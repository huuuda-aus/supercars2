# Fonts

`Orbitron.ttf` is **Orbitron** (a variable font, weights 400 to 900) by The Orbitron Project Authors
(https://github.com/theleagueof/orbitron), downloaded from Google Fonts' repository
(https://github.com/google/fonts/tree/main/ofl/orbitron) and used unmodified under the SIL Open Font License 1.1: see
`LICENSE-orbitron.txt` (the copyright notice and licence travel with the font).

It is bundled with the game (not loaded from Google's servers), so the game works offline.

Orbitron has no middle dot or arrow characters; the few the UI uses come from the browser's fallback font.
